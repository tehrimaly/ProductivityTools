# Task 11: AI Assisted Frontend and Productivity Tools

## Overview

This task involved exploring a set of AI assisted frontend and productivity tools, using some hands on and reading up on others to understand where they fit into a modern development workflow.

## Tools Used Hands On

### Excalidraw

Used to sketch out the architecture for Aria, my voice powered RAG assistant. Mapped the flow from voice input through Vapi.ai, into the FastAPI backend, out to ChromaDB and Groq for retrieval and generation, and back to the user as a spoken response. Helpful for laying out a project visually before touching any code.

### Overleaf

Used to format my resume in LaTeX. Gave me a cleaner and more consistent result than formatting in Word, especially for keeping spacing and section structure tight.

### v0 by Vercel

Used to generate and iterate on UI for my portfolio site and for AutoLux, my MERN stack luxury car dealership project. You describe what you want in plain language and it builds a working interface in seconds, which saved a lot of time on layout work I would otherwise have hand coded.

### shadcn.io

A large marketplace of pre built React and Tailwind blocks. Pulled a few components to see how quickly a decent looking UI comes together without designing everything from scratch.

## Tools Explored

### 21st.dev

The community driven registry version of shadcn, now also offering agent templates such as a web scraper agent, an API designer, and a data analyst agent, alongside its UI components.

### Magic UI

A library of animated React and Tailwind components meant to pair with shadcn/ui as a polish layer, useful for adding motion and detail without building animations manually.

### Anima

Converts a live website into an editable Figma file, useful for reverse engineering an existing design into something you can actually work with and modify.

### Figma Dev Mode and MCP

Lets AI coding tools such as Claude Code or Cursor pull exact design specifications, including spacing and colors, directly from a Figma file instead of relying on manual inspection.

### Ollama

Runs open weight AI models locally through the command line. Also supports cloud hosted models for larger workloads, and integrates with coding agents such as Claude Code.

### Google Antigravity

An agent first development platform that can plan, execute, and verify coding tasks across an entire workspace with minimal manual intervention.

## Takeaway

The hands on tools, Excalidraw, Overleaf, v0, and shadcn.io, are now part of my regular workflow for planning, documentation, and UI work. The remaining tools are good to have in mind for future projects where local model access, design to code handoff, or autonomous agent execution become relevant.
